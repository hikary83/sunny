# 🏊‍♂️ 수영 마스터: 바이브 코딩 게임 프로젝트

## 📖 기획 및 시나리오 (Game Design Document)

### 1. 기본 컨셉
주인공이 열심히 훈련(컴퓨터 기초 미션)을 해서 코인과 수영 능력을 얻고, 상점에서 장비를 보충한 뒤 단계별 수영 목표를 달성하는 교육용 성장 미니게임.

### 2. 교육형 체육관 미션 (컴퓨터와 친해지기!) 🎓
단순 노동이 아닌, 7살 아이가 컴퓨터 마우스와 키보드에 자연스럽게 익숙해지도록 난이도가 올라가는 시스템.
고난이도 미션을 성공할수록 더 많은 코인을 보상으로 받음.

#### 🖱️ 마우스 훈련 미션
* **1단계 (클릭 연습)**: 화면에 나타나는 과녁/물방울을 마우스로 클릭해서 터트리기.
* **2단계 (드래그 연습)**: 쓰레기를 마우스로 꾹 눌러서 쓰레기통으로 드래그 앤 드롭하기. (추후 구현)
* **3단계 (정밀 조작)**: 좁은 길을 마우스 커서로 벽에 닿지 않고 통과하기. (추후 구현)

#### ⌨️ 키보드 훈련 미션
* **1단계 (자리 익히기)**: 화면에 나오는 단일 알파벳(A~Z)이나 한글 자음/모음을 보고 똑같은 키 누르기.
* **2단계 (짧은 단어)**: '사과', 'APPLE' 등 짧고 쉬운 단어 타이핑. (추후 구현)
* **3단계 (짧은 문장)**: 띄어쓰기가 포함된 문장 타이핑 연습. (추후 구현)

### 3. 상점 및 수영 시스템
* 벌어들인 코인으로 아이템(드링크, 초코바, 물안경, 오리발 등)을 구매.
* 목표치(초/중/고급)에 맞춰 수영 도전. 실패 시 다시 체육관으로 돌아와 훈련 진행.

  - 마우스 훈련: 터치 팝(Touch-to-Pop) 지원.
  - 키보드 훈련: 화면 하단에 블록형 **가상 QWERTY 키패드** 렌더링 및 모바일 입력 완벽 지원.
- [x] **상점 시스템 및 아이템 구현**: 체력 드링크(체력 즉시 +50), 오리발(수영 속도 증가), 물안경(장애물 피해 50% 반감) 구매 기능 및 세로형 모바일 상점 UI 적용.
- [x] **난이도별 배경 차별화**: 초급(실내 수영장 `bg_water.png`), 중급(계곡 `bg_valley.png`), 고급(심해 바다 `bg_ocean.png`) 난이도별 타일 종스크롤 맵 연동.

## 🚀 구글 앱스 스크립트(GAS) 웹앱 배포 가이드
이 프로젝트는 모바일 브라우저에서 편리하게 구동하기 위해 Google Apps Script의 웹앱(Web App) 배포 방식으로 최적화되어 있습니다.

### 1. 단일 빌드본 통합하기 (Merge)
구글 앱스 스크립트 에디터에 코드를 쉽게 올리기 위해 HTML, CSS, JS 파일을 하나로 묶어주는 파이썬 스크립트를 작성해 두었습니다. PC 터미널에서 아래 명령을 실행합니다:
```bash
python "design source/build_gas_html.py"
```
* 빌드가 완료되면 프로젝트 루트 폴더에 **`gas_deploy.html`** 파일이 생성됩니다.
* 이 파일은 깃허브 원격 저장소(`https://raw.githubusercontent.com/hikary83/sunny/...`)를 자동으로 바라보도록 이미지 경로를 변환하고 모든 코드와 디자인을 하나로 합친 파일입니다.

### 2. 구글 앱스 스크립트 배포 순서
1. [구글 앱스 스크립트](https://script.google.com/)에서 새 프로젝트를 생성합니다.
2. `Code.gs` (서버사이드 스크립트) 파일에 아래 코드를 적고 저장합니다:
   ```javascript
   function doGet() {
     return HtmlService.createTemplateFromFile('Index')
         .evaluate()
         .setTitle('수영 마스터 게임')
         .addMetaTag('viewport', 'width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no')
         .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
   }
   ```
3. 에디터 좌측 **[+] 파일 추가** ➡️ **[HTML]** 클릭 후 파일 이름을 **`Index`**로 만듭니다. (자동으로 `Index.html`이 됨)
4. 생성된 **`gas_deploy.html`** 파일 안의 전체 코드를 복사해서 GAS 에디터의 `Index.html`에 붙여넣고 저장합니다.
5. 우측 상단 **[배포]** ➡️ **[배포 관리]** (또는 [새 배포]) 클릭 ➡️ 유형은 **[웹 앱(Web App)]**을 선택합니다.
   * **웹 앱을 실행할 사용자**: `나 (본인 구글 계정)`
   * **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`**
6. 배포를 실행하고 발급되는 **웹 앱 URL**을 스마트폰 브라우저에 입력해 아들과 함께 즐겁게 플레이합니다!
