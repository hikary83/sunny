# 🏊‍♂️ 수영 마스터: 바이브 코딩 게임 프로젝트

## 📖 기획 및 시나리오 (Game Design Document)

### 1. 기본 컨셉
주인공이 열심히 운동(미션)을 해서 코인과 수영 능력을 얻고, 상점에서 체력과 장비를 보충한 뒤 단계별 수영 목표를 달성하는 성장형 미니게임.

### 2. 캐릭터 선택 화면
* 게임 시작 시, 플레이어는 3~4가지의 개성 있는 캐릭터 중 하나를 선택해서 시작할 수 있다.

### 3. 목표 (난이도별 스테이지)
유저는 초급/중급/고급 중 하나를 선택해 도전할 수 있다.
* **[초급] 동네 수영 대회 1등 하기 (목표 A)**: 수영장에 들어가서 라이벌보다 빨리 도착하기
* **[중급] 바닷속 보물상자 찾기 (목표 B)**: 잠수 능력을 키워 바닷속 깊은 곳까지 다녀오기
* **[고급] 환상의 섬 도달하기 (목표 C)**: 아주 먼 거리를 체력 안배를 하며 헤엄쳐 가기

### 4. 미션 (코인 벌기 및 능력치 상승)
수영을 하기 전, 체육관 같은 곳에서 미션을 수행해 코인을 번다. (게임을 만들면서 계속 추가 예정)
* 스페이스바 연타하기 (윗몸 일으키기)
* 장애물 피하기 (러닝 머신)
* 타이밍 맞추기

### 5. 상점 시스템 (아이템)
미션으로 번 코인을 사용해 체력을 회복하거나 수영 능력을 올린다.
* **에너지 드링크**: 체력 소폭 회복
* **초코 에너지바**: 체력 대폭 회복
* **물안경**: 시야 확보 (특수 능력)
* **오리발**: 수영 속도 대폭 상승

### 6. 게임 오버 및 부활 시스템
* 수영 중 체력이 0이 되면 **"다시 도전 / 포기"** 선택창이 나타남.
* **다시 도전** 선택 시: 수영장이 아닌 '미션(체육관)' 맵으로 이동. 미션을 통해 코인을 벌고 체력을 다시 채워서 재도전할 수 있게 함!
